# 日常知识记忆与查询

## 1. 唯一入口与意图路由

入口仅为知识问答或知识点文本（命令参数或对话输入），按以下规则智能判断意图并直接执行；仅在意图或匹配结果真正无法判断时才询问用户：

| 输入 | 行为 |
|---|---|
| 无参数 | 读取 `memory/index.md`，返回总索引概览（模块清单、各模块碎片数与最近更新） |
| 知识问题，查到唯一 | 返回该碎片完整内容；发现内容过时或输入携带新信息则同步更新该条（frontmatter `更新日期` 刷新，正文按最新信息改写） |
| 知识问题，查到多个候选 | 一并返回候选清单供定位；能明确命中其一且输入携带新信息时更新之，无法判断时列候选询问 |
| 知识问题，未查到 | 告知未记忆该知识点；输入同时携带知识内容则判定归属模块，自动新增碎片并同步索引，仅提问则引导用户给出知识后即记录 |
| 明确操作指令（删除/更新/重组某知识等） | 执行对应增删改查，同步索引 |

**检索规则**：以问题或知识点为关键词，用 Bash（`rg`/`find`/`grep`）检索全部碎片文件名、frontmatter `知识点`/`标签` 字段与各模块索引条目；关键词包含与语义相近均算命中，不依赖其他查找类工具。

## 2. 目录铁律（不可违反）

- 一切文件操作**严格局限在当前工作目录的 `memory/` 目录内**：新增、修改、删除只允许作用于该目录内的文件，不在目录外产生或修改任何文件——同一工作目录可能有多个技能并行运行，零外溢是硬约束
- 目录不存在时自动创建完整骨架（根索引 + 首个模块目录 + 模块索引）
- 检索与列目录一律用 Bash 等价命令完成

## 3. 目录结构

```
memory/
  index.md            # 总索引（必须存在，缺失即按模板重建）
  <模块目录>/          # 知识碎片必须按模块归档，不允许散落在根下
    index.md          # 模块索引（必须存在）
    <知识碎片>.md     # 每条知识碎片一个文件
    files/            # 按需：当前知识碎片需要关注的文件统一整理到此目录
```

## 4. 知识碎片模板

```markdown
---
知识点: <一句话知识点名>
标签: <关键词，多个逗号分隔>
创建日期: YYYY-MM-DD
更新日期: YYYY-MM-DD
---

## 怎么做

<工具、地址、步骤、账号、注意事项等操作细节，按需>

## 变更

- [YYYY-MM-DD] <创建时写入一行；后续每次更新追加，新的在上>
```

文件名 = 知识点名（去除路径非法字符），与 frontmatter `知识点` 保持一致，保证索引与检索直观。

## 5. 索引模板

根 `index.md`（总索引）：

```markdown
# 知识总索引

| 模块 | 碎片数 | 最近更新 |
|---|---|---|
| <模块目录名> | N | YYYY-MM-DD |
```

模块 `index.md`（模块索引）：

```markdown
# <模块名>

| 知识点 | 标签 | 更新日期 |
|---|---|---|
| [<知识点>](<碎片文件>.md) | xxx | YYYY-MM-DD |
```

## 6. 索引同步

每次新增/更新/删除碎片后，立即同步刷新两级索引：所属模块 `index.md` 对应行，根 `index.md` 对应模块行（碎片数、最近更新日期）。发现索引与碎片文件不一致时，以碎片文件为准重建索引。

## 7. 模块自动梳理

- **归属判定**：新增碎片时按语义匹配现有模块，无合适模块则新建；模块划分维度（按业务域、工具类型、主题等）自行判断，不询问用户
- **拆分与合并**：模块内容过多过杂时自动按更细维度拆分（模块目录是最小粒度，拆分后仍过杂则按子主题再拆）；模块过空时合并。过程中完成碎片文件迁移与两级索引重建，全程不询问用户
- **命名**：模块目录名中文 ≤10 字、英文 ≤30 字符，简洁清晰
- **与时俱进**：知识内容过时随时直接改写对应碎片并同步索引；结构演化导致现有划分不清晰时，随时重命名、重组模块（旧目录名不作历史包袱）；迁移时保持碎片内容不变，仅调整归档位置与索引
