# 命令行透明展示规则

定义命令执行前的明文回显规则，供插件内所有命令全局遵守。目的：让用户一目了然看到实际执行的每条命令，便于人工复现，无需事后追问。

## 强制规则

每次调用 Bash 工具前，必须在**同一条消息的正文**中先输出要执行的原始命令：

- 以 `$ ` 为前缀，命令本体紧跟其后，**单独一行**
- 先输出该行，**再**发起 Bash 工具调用

**正例**（先输出正文一行）：

```
$ git diff HEAD
```

然后调用 Bash 工具执行 `git diff HEAD`。

**反例**：

- ❌ 只调用 Bash 工具，正文不展示命令——用户看不到执行了什么
- ❌ 把命令混在长段落叙述里——无法一眼定位
- ❌ 执行完才补充说明命令——必须在执行前展示
- ❌ 用自然语言转述（如"检查了 git 状态"）而不给原始命令

## 截断规则

- 命令长度 ≤ 200 字符：**完整展示**
- 命令长度 > 200 字符：保留前 200 字符，末尾加 `...` 示意

## 边界情况

- **复合命令**：含 `&&`、`;`、管道等的复合命令，作为**一个整体原始命令**展示，不拆分、不省略
- **多条命令**：同一轮需连续多次调用 Bash 时，每次调用前各自单独回显对应命令
- **回显即实参**：回显内容必须与实际传入 Bash 工具的 `command` 参数完全一致，禁止回显与实际执行不同的命令
- **无例外**：所有 Bash 工具调用（git、构建、测试、脚本、探测性命令等）一律回显
